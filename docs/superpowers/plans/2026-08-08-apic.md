# APIC (Local + IO) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Repo note:** this is not a git repo, so there are no `git commit` steps. Each task ends with the build + QEMU verification run (the same command is the "checkpoint").

**Goal:** Replace the 8259 PIC with a Local APIC (timer + interrupts) and an IO-APIC (device interrupt routing), verified in QEMU, so the kernel has the interrupt substrate SMP and modern timer behavior require.

**Architecture:** Read-only memory-mapped registers via `HHDM_BASE + phys` (the MMIO regions are already reserved in `shared::boot::mod::MMIO_DEVICE_REGIONS`). Local APIC at `0xFEE0_0000`, IO-APIC at `0xFEC0_0000`. Boot order: disable PIC (mask + disable cascading) → enable APIC via MSR 0x1B (APIC_BASE) → init LAPIC → calibrate LAPIC timer against PIT → reprogram IDT vectors to the APIC base (0x20+) → route the timer through the LAPIC, device IRQs through the IO-APIC → enable APIC-mode end-of-interrupt (EOI write to `0xFEE0_00B0` instead of PIC `0x20`).

**Tech Stack:** Rust `#![no_std]` kernel, x86_64, memory-mapped MMIO, MSRs, QEMU `-enable-kvm` (LAPIC timer works under KVM), `-serial file:` verification.

## Register map (MMIO, offset from base)

Local APIC (`0xFEE0_0000`, 4-byte registers, 16-byte stride):
| Offset | Register | Purpose |
|---|---|---|
| 0x020 | LAPIC_ID | Read: this CPU's APIC ID |
| 0x030 | LAPIC_VERSION | Bit 24: has CMCI; low 8 bits version |
| 0x080 | TPR | Task priority; write 0 |
| 0x0D0 | LDR | Logical destination (SMP later) |
| 0x0E0 | DFR | Flat model (SMP later) |
| 0x0F0 | SVR | Bit 8 `APIC_ENABLE` — master on/off switch |
| 0x320 | LVT_TIMER | Timer vector + mode + mask |
| 0x350 | LVT_LINT0 | External NMI (mask it) |
| 0x360 | LVT_LINT1 | External NMI (mask it) |
| 0x380 | TIMER_INIT_COUNT | Count-down initial value |
| 0x3E0 | TIMER_CURRENT_COUNT | Read-only current value |
| 0x3F0 | TIMER_DIVIDE | Divider 0b1011 = 1 |

IO-APIC (`0xFEC0_0000`, `IOAPIC_REGISTER`/`IOAPIC_WINDOW` at offsets 0x00/0x10, 32-bit):
| Register | Purpose |
|---|---|
| 0x00 (REG) | select register to read/write via WINDOW |
| 0x10 (WINDOW) | data for the selected register |
| reg 0x00 | IOAPIC_ID |
| reg 0x01 | IOAPIC_VERSION (bits 24-27 = max redirection entries) |
| reg 0x10 + 2*index | IOREDTBL[index], low 32 bits: vector, delivery mode, dest mode, polarity, mask |
| reg 0x10 + 2*index + 1 | IOREDTBL[index], high 32 bits: destination APIC ID / logical |

Vector constants: use the existing `PIC_1_OFFSET = 32` convention — keep `TIMER_INTERRUPT_ID = 32`, `KEYBOARD_INTERRUPT_ID = 33` so `time.rs`/`interrupts.rs` call sites don't change.
